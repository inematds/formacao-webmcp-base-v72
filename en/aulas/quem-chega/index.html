Lesson 6 · 15 min

Who's arriving: bots by purpose and signed agents (the concept)

Not every AI bot that visits your site does the same thing: some index for search, others read when a person asks, others collect for training. The robots.txt file asks by purpose, but it doesn't prove who is who. In this lesson you read your robots.txt by purpose and learn what the Web Bot Auth draft proposes for identifying the agent.

Purpose is decided in robots.txt; identity only with a signature. Security in depth for this is course 4.

02 · Request × identity

What each one solves.

1. robots.txt

One group per User-agent with Allow and Disallow. Bots that follow the rule respect it; the CDN or firewall is what enforces it.

Write the decision by purpose and note the reason in a comment. The full step-by-step is in lesson 6 of the inemaSEO Foundation course.

2. User-Agent

Each bot introduces itself by name in the User-Agent header. It's just text: any program can write "GPTBot". It's good for statistics, not for trust.

3. Signature

In the draft-ietf-webbotauth-httpsig-protocol draft (Sept/2026, Cloudflare and Google, an IETF working group document, not yet an RFC), the agent signs the request and sends the Signature-Agent header; the keys live in a JWKS directory at a well-known URI.

On Cloudflare, since 07/01/2026, signed agents count as Verified, with the field "Direct versus Intermediary access".

What changes for you nowNothing to install in this course. Knowing it exists helps you read your CDN dashboard and not trust a bot's name alone.

03 · The robots.txt read by purpose

The robots.py reads a robots.txt (file or URL) and tells you, by purpose, who can get into the root of the site. Simplified rule: only the root "/"; partial = blocks some paths.

Terminal · the example robots.txt
cd ~/projetos/formacao-webmcp-base-v72/kit
python3 robots.py site/robots.txt; echo "saída: $?"
Template · your site
cd ~/projetos/formacao-webmcp-base-v72/kit
python3 robots.py https://<your-site>/robots.txt; echo "saída: $?"
Example from the repository

The example shop allows search and user action and blocks training. Googlebot and Bingbot don't have their own group: the rules of * apply, which blocks only /admin/ (that's why "parcial").

04 · Practice

The example, your robots.txt, and the decision noted.

E1 · The example by purpose

5 min

Done when: python3 robots.py site/robots.txt → treino line with GPTBot bloqueado and saída: 0.

E2 · Your robots.txt

10 min

Run the template with your site's address. Copy the busca, ação do usuário, and treino lines into the plan (the "Quem pode entrar" section).

Done when: the output has the busca, ação do usuário, and treino lines and ends with saída: 0.

E3 · What really counts

10 min

Open your CDN or hosting dashboard and check whether there is AI bot blocking or a list of verified agents. Note whether it agrees with the robots.txt.

Done when: the plan has a line saying which CDN (or "no CDN") and whether the dashboard agrees with the robots.txt.
